# infra-labs

Мои лабы и DevOps-практика.

## День 1 — Linux
- Умею перемещаться по ФС (pwd, cd, mkdir).
- Вижу скрытые файлы (ls -la).
- Написала скрипт с датой, сделала его исполняемым (chmod +x).
- Поняла, что chown требует sudo.
- Исправила ошибку bad interpreter (echo -e vs printf).

## День 2 — Процессы, порты и логи
- Смотрю процессы через `ps aux` и `top`. Умею находить PID и убивать процессы (`kill`).
- Смотрю открытые порты через `ss -tulnp`. Увидела, что порт 8080 занят (Tomcat), а порт 22 (SSH) не слушается.
- Выяснила, что в моей ВМ не установлен SSH-сервер (`systemctl status ssh` -> `Unit ssh.service could not be found`).
- Проверила работу `cron` — служба активна, запускает задачи по расписанию.
- Научилась читать логи ошибок (`journalctl -p err`). В ВМ они связаны с ядром VirtualBox, это нормально.

## День 3 — Docker
- Установила Docker, добавила пользователя в группу docker.
- Запустила тестовый контейнер `hello-world`, посмотрела списки (`docker ps`, `docker ps -a`).
- Запустила веб-сервер Nginx в контейнере с пробросом портов (`-p 8081:80`).
- Научилась смотреть логи (`docker logs`), останавливать (`stop`), запускать (`start`) и удалять (`rm`) контейнеры.
